## Суть решения

**Техрадар** показывает движение ландшафта: в **Adopt** — облачная платформа, Kafka, CDC, Lakehouse, витрина данных, Data Mesh, DDD, IAM; в **Trial** — каталог, semantic layer, контракты данных, GitOps, DevSecOps, Observability, Data Governance; в **Assess** — MLOps; в **Hold** — легаси (SQL Server 2008, ESB Camel, PowerBuilder, BI-кастомизации, Power BI). Каждая карточка связана с бизнес-сценариями B1–B6.

**Роадмап** — 4 этапа: (0) фундамент ИБ/комплаенс → (1) интеграционный слой + миграция DWH → (2) витрина данных в проде + остановка роста логики в DWH → (3) онбординг партнёров + переключение последних источников записи (PowerBuilder, ESB) с верификацией и только затем read-only/вывод легаси + DR-учения. Для каждого этапа указаны ожидаемые результаты, ответственные команды, ресурсы и бизнес-обоснование (скорость решений, качество сервиса, снижение затрат, масштабирование).
