Поэтапная миграция: DWH замораживается на запись, исторические данные перетекают через CDC в доменные платформы, потребители переключаются на data-продукты, затем DWH выводится. Риск контролируется переключением по срезам.

**Поддерживает сценарии:** B6 (миграция легаси-DWH), отказоустойчивость и вывод устаревшего SQL Server 2008.
