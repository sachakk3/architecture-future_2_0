Синхронные операционные вызовы между доменами (скоринг, оплата, справки) через единый шлюз с квотами и контролем доступа.

**Поддерживает сценарии:** B4 (оплата мед. услуг, кредит на лечение в реальном времени), B5 (API для партнёров).
