Захват изменений из легаси-DWH и банковского ядра в реальном времени; основной механизм миграции исторических данных в доменные платформы.

**Поддерживает сценарии:** B6 (миграция SQL Server 2008 без остановки бизнеса), актуальность data-продуктов.
