# Технологический радар «Будущее 2.0» (релиз 2026-11-09)

**Интерактивная версия радара** — [`practicum-techradar/`](practicum-techradar/) (генератор `aoe_technology_radar` v4, сборка в `build/`, локальный просмотр `npm run serve` → `http://localhost:3000/techradar`).

**Роадмап изменений:** [`roadmap.md`](roadmap.md)

## Кольца

| Кольцо                 | Значение                                                            |
| ---------------------- | ------------------------------------------------------------------- |
| **Adopt — применяем**  | Целевые технологии: используем осознанно, развиваем компетенции     |
| **Trial — пробуем**    | Пилотируем на ограниченном контуре                                  |
| **Assess — оцениваем** | Отслеживаем применимость                                            |
| **Hold — выводим**     | Легаси и подходы, от которых отказываемся в горизонте трансформации |

Сценарии: **B1** — быстрая отчётность; **B2** — кросс-доменные KPI; **B3** — ИИ-анализ мед. данных; **B4** — новый финтех-сервис; **B5** — подключение партнёров; **B6** — вывод легаси-DWH.

## Квадрант «Методологии и паттерны»

| Технология                             | Кольцо    | Сценарии   | Комментарий                                                                                              |
| -------------------------------------- | --------- | ---------- | -------------------------------------------------------------------------------------------------------- |
| Data Mesh                              | **Adopt** | B1, B2, B5 | Данные принадлежат доменам; data-продукты с контрактами; витрина данных собирает срезы по уровню доступа |
| Domain-Driven Design (bounded context) | **Adopt** | B3, B4, B5 | Границы доменов = границы контекстов; связь через контракты, а не общие таблицы                          |
| Strangler Fig + CDC-миграция           | **Trial** | B6         | Управляемый вывод DWH без остановки бизнеса                                                              |
| Data Contracts                         | **Trial** | B1, B2, B5 | Независимое развитие доменов при гарантированном качестве данных                                         |
| Team Topologies                        | **Trial** | все        | Платформенная команда снижает нагрузку на домены                                                         |
| GitOps (IaC)                           | **Trial** | B5, B6     | Онбординг домена из шаблона, воспроизводимые DR-контуры                                                  |
| DevSecOps                              | **Trial** | комплаенс  | Безопасность в конвейере: медицинская и банковская тайна                                                 |
| Централизованный монолитный DWH-подход | **Hold**  | —          | Причина P1/P2/P9; заменяется Data Mesh                                                                   |
